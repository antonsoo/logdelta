logdelta

diff logs by meaning, not by bytes

Source

What happened in the failing run that didn't happen in the good one?

Paste a known-good run and the run you're investigating. logdelta masks what always differs (timestamps, IDs, IPs, durations), groups lines into templates, and reports the templates that are new, gone or changed in frequency, and the values that flipped. This is the Rust library itself, compiled to WebAssembly: your logs stay in this tab.

Numbers are normally masked. Watch status or exit codes to catch value changes even when the log's shape stays the same. One JSON Pointer per line, such as /http/status.

Keep routes or services separate for every watched field. One JSON Pointer per line, up to four. A missing group key makes the watch incomplete; leave blank to pool records.

Options

Up to 8 baselines, 25 MiB per log after decompression and 50 MiB total. Use the CLI for larger logs.
